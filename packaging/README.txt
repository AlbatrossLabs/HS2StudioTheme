Studio Theme v{VERSION} for Honey Select 2 Studio
=================================================
Albatross Labs - https://github.com/AlbatrossLabs/HS2StudioTheme

Restyles Studio's dated menus in a clean glass look: glass panels, the Windows
system font, line icons, Apple-style check boxes and sliders, a Finder-style
workspace and pickers, a right-click menu for characters, and folders for the
tool buttons. Buttons keep their places and do what they always did.

REQUIREMENTS
  - Honey Select 2 with BepInEx 5 and HS2API (KKAPI) - any recent BetterRepack has both.
  - Optional: MoarCamz, HS2PE, FK & IK, HSUS - their panels and buttons are themed too.

INSTALL
  1. Close the game.
  2. Extract the zip into your Honey Select 2 folder (the one with HoneySelect2.exe).
     Everything lands in BepInEx\plugins\HS2StudioTheme\ :
       HS2StudioTheme.dll         the plugin
       README.txt                 this file
       CHANGES.txt                what's new in this version
       LICENSE.txt                Studio Theme's licence (MIT)
       LICENSE-tabler-icons.txt   licence for the icons (Tabler Icons, MIT)
  3. Updating: overwrite the old files.

USE
  Start Studio: the theme is on straight away.
  Settings: F1 (Configuration Manager) > Studio Theme. Turning "Enabled" off puts
  Studio's original look back at once, no restart needed.
  Right-click a character in the scene for its menu. Drag the tool buttons at the
  bottom left onto each other to make folders.
  Log: output_log.txt in the game folder.
  Full history: CHANGELOG.md on GitHub.
